

#  BC WildWatch

**BC WildWatch** is a smart campus safety platform that enables students to report dangerous or nuisance animal sightings in real time. The system transforms a classroom prototype into a scalable, web-based application using modern technologies and free-tier tools.

---

##  Overview

BC WildWatch empowers campus communities by providing a centralized system for reporting and monitoring wildlife hazards such as snakes, bees, stray animals, and other environmental risks. The platform integrates automation, analytics, and secure access to enhance safety and response efficiency.

As described in your project documentation, the system is designed to be **secure, scalable, and publicly accessible**, while leveraging tools like Microsoft Power Platform and GitHub for deployment .

---

##  Key Features

*  **Real-Time Reporting**
  Students can quickly submit animal sightings through an intuitive interface.

*  **Secure Authentication**
  Supports Microsoft 365-based login for controlled access.

*  **Smart Assistance**
  Integrated chatbot for guidance and support.

*  **Automated Alerts**
  Instant notifications for reported hazards.

*  **Data Analytics Dashboard**
  Visual insights powered by Power BI.

*  **Cloud-Based Deployment**
  Hosted using GitHub Pages and modern web hosting tools.
